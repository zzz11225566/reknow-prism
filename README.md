# 炼知 ReKnow · 知识炼金场

炼知 ReKnow 是知乎黑客松 2026「知识炼金场」赛道的前端原型。它把知乎收藏从“内容仓库”重新组织为一条可以理解、验证、迁移和长期积累的知识路径。

第一版包含两个核心模块：

- **收藏拆解**：模拟连接知乎账号，将收藏聚类为可新建的知识类别，并用一套可配置的短步骤学习文章。
- **炼金宇宙**：每个主题成为“一颗恒星 + 多颗行星”的星系，完成拆解的文章成为行星，掌握后点亮；支持搜索知乎内容和自己的宇宙。

两个模块都带有固定指南针、模块导引，以及固定的“返回上一界面”和“返回主页”按钮。

## 核心流程

1. 模拟同步知乎收藏。
2. AI 将收藏聚合为知识主题。
3. 用户选择文章，完成默认学习路径：
   - 看懂回答：问题、结论与适用对象。
   - 拆出依据：事实、经验、假设和依赖条件。
   - 追问根基：第一性推理、理想形态、边界与反例。
   - AI 抬杠：输入“我学会了”，由 AI 压力测试理解。
   - 化为己用：把知识转化为现实行动和长期问题。
4. 完成拆解后，文章形成行星；标记掌握后点亮。
5. 用户可以把主题星系加入个人炼金宇宙，或从知乎搜索中加入待拆解内容。
6. 文章内置 AI 问答和“AI 抬杠”：发送“我学会了”后，AI 会继续追问前提、边界和反例。

## 设置层级

- **中心设置**：位于模块右上角，控制模块开关、主题排列、学习步骤的启用与顺序、学习默认值、宇宙标签、关系链和性能。
- **区域小设置**：位于主题卡片、文章步骤和单个星系的右上角，只覆盖当前区域的颜色、顺序、内容深度、AI 语气、公转速度等。
- 小设置不会复制或删除中心数据；模块关闭、主题隐藏、步骤停用后，原有进度和覆盖项都会保留。
- **文章小设置**：单独控制当前文章开启哪些学习步骤，不会影响其他文章。
- **无边记**：每个主题拥有独立白板，支持便签、文本、矩形、画笔、橡皮、平移、缩放和撤销。

## 设计原则

- 浅色工作台负责高效率阅读、拆解与整理。
- 深色宇宙负责空间化浏览、定位和长期积累。
- 当前版本使用本地模拟数据，所有状态保存在 `localStorage`。
- 前端不保存任何 API 密钥。后续知乎与 AI 请求统一经过后端。
- 宇宙采用正向旋转、独立平移和围绕当前视角中心缩放；总览只显示主题名，放大或单击星系后显示文章名。
- 单击星系会进入占满画面的星系视图；再次双击中心恒星可打开星系小设置。

## 运行

直接双击 `index.html` 即可离线打开。

也可以启动本地静态服务器：

```bash
npm start
```

默认地址：`http://127.0.0.1:4173`

运行前端静态检查：

```bash
npm test
```

## 文件职责

| 文件 | 职责 |
| --- | --- |
| `index.html` | 应用骨架、两个主视图、设置弹窗 |
| `styles.css` | 浅色工作台与深色宇宙的视觉系统、响应式布局 |
| `data.js` | 主题、文章、拆解内容和搜索模拟数据 |
| `api.js` | 知乎数据适配层，当前为本地模拟实现 |
| `app.js` | 收藏聚类、文章拆解、状态持久化、设置和页面交互 |
| `universe.js` | Three.js 星系、行星、镜头、搜索和星球详情 |
| `server.js` | 零依赖静态服务器和健康检查 |
| `verify.cjs` | 不依赖浏览器与第三方包的静态验证 |

## 后续 API 接入

`api.js` 已把数据入口集中在四个方法：

- `connectAccount()`
- `syncCollections()`
- `decomposeArticle(articleId)`
- `searchZhihu(query)`

后续接入官方授权接口时，这些方法改为请求后端即可。浏览器端不应持有知乎 Access Token、模型 Key 或任何长期凭证。

建议的后端接口：

```text
POST /api/zhihu/oauth/start
GET  /api/zhihu/oauth/callback
POST /api/zhihu/sync
GET  /api/zhihu/search?q=
POST /api/article/:id/decompose
GET  /api/me/universe
PUT  /api/me/universe
```

## 当前边界

- 第一版为前端演示，模拟知乎数据和 AI 拆解结果。
- 真实原文、收藏夹和搜索需要后续接官方 API。
- 宇宙目前使用程序化 3D，不包含外部模型资产。
- `vendor/three.min.js` 来自 Three.js 开源项目，遵循其原始许可证。
